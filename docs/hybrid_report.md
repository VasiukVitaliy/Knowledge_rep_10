## Pre-filter за метаданими

Фільтр застосовується до ранжування: BM25 обнуляє, а dense виключає чанки, що не проходять умову. «Вибірка» — запити, для яких еталонна фраза є хоча б в одному документі, що проходить фільтр. «Витоки» — скільки чанків у видачі порушують умову (має бути 0); «Влучання поза вибіркою» — скільки запитів знайшли відповідь у документі, що фільтр відсікає (має бути 0).

| Фільтр | Чанків проходить | Запитів у вибірці | recall@5 на вибірці | Витоки | Влучання поза вибіркою |

| type = статистика | 8 | 4 | 1.00 | 0 | 0 |
| type = нормативний | 129 | 0 | — | 0 | 0 |
