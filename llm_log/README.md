# Журнал взаємодії з LLM

Один файл на сеанс: `llm_log/YYYY-MM-DD_<призначення>.md`. Заповнюйте **реальними** даними зі свого чату — нічого не вигадуйте.

```
Дата і час:
Модель і версія:
Параметри (temperature, seed):
Призначення: (напр., генерація кандидатів запитів до золотого набору)
Версія підказки: v1
Підказка (текст):
Сирий вихід (повністю):
Рішення людини: що прийнято / виправлено / відхилено і чому
```
